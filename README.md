# Rejected Olympic Sports — make.fun entry

This repository holds my submission to the make.fun contest
[Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da),
which asked for an invented sport the Olympics supposedly turned down.

## The submitted line

> Synchronized parallel parking: four drivers, one spot outside a bakery on Sunday, judged on pure panic.

## Why this one

Three candidates were drafted and scored against the judging priorities
spelled out in the contest RULES: instant comprehension on a first read,
then surprise, economy, novelty, and how cleanly the line reads aloud.
Two of the drafts — a race to empty an overflowing inbox and a wrestling
match over a pivot table — never escaped office humour. The parking line
won because "synchronized" is a genuine Olympic adjective, and dropping
it into a mundane Sunday scramble for the last space outside a bakery
gives the joke its jolt.

## Running it

`main.py` needs nothing beyond Python 3's standard library. It performs
no network calls and produces the same result every time: the fixed
entry text lands in `entry.txt` under `$MAKEFUN_OUTPUT_DIR`.
